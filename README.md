# Recruitment Catalogue Demo

This is an example repository providing a Next.js site containing a number of structural errors. Applicants will be required to identify and suggest corrections to them.

## Getting Started

Start by installing dependencies. We recommend PNPM but you can also use NPM or Yarn.  
For the sake of argument, all commands will use `npm`.

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
